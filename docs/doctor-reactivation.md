# Bônus individual do médico — substituído

Em 14/11/2026, o usuário decidiu substituir o bônus individual de 30 pontos pelo [reconhecimento coletivo da equipe](team-recognition.md).

A migração 011 desativa o bônus antigo. A API bloqueia reativação e os endpoints legados não geram novos pontos, mesmo com uma configuração antiga ativa. Registros históricos são preservados, sem conversão para prêmio coletivo ou dinheiro.

A proposta de pagamento coletivo permanece em discussão. O painel oferece simulação identificada como tal; não há pagamento automático.
